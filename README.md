✨ AI Text Improver

An AI-powered web application that enhances text clarity, grammar, and tone using prompt engineering with Ollama + Flask.

---

🚀 Features

- ✍️ Improves grammar and sentence structure
- 🎯 Enhances clarity and readability
- 🎭 Adjusts tone (formal, casual, etc.)
- ⚡ Runs locally — no paid APIs required
- 🧠 Built using prompt engineering

---

🛠️ Tech Stack

- Python (Flask)
- Ollama (LLM)
- HTML, CSS
- Prompt Engineering

---

📸 How It Works

1. User enters text
2. Selects improvement mode
3. Backend sends prompt to Ollama
4. AI processes and improves text
5. Output is displayed instantly

---

💻 Setup Instructions

1. Install Ollama
   https://ollama.com/download

2. Run a model (example):

ollama run llama2

3. Install dependencies:

pip install flask requests

4. Run the app:

python app.py

5. Open in browser:

http://127.0.0.1:5000
